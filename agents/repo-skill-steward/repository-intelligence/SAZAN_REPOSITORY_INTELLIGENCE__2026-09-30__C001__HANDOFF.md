## Completed baseline

The Repository Intelligence baseline now covers:
- L0 intake and provenance;
- L1 context packaging;
- L2 semantic code graph;
- L3 architecture presentation;
- L4 repository wiki and Q&A;
- L5 guarded semantic editing;
- L6 evidence-backed clean-room reverse engineering;
- L7 deterministic evidence and promotion gate.

## Non-negotiable controls

- no direct default-branch semantic mutation;
- no auto-promotion;
- parent Repo & Skill Steward remains final promotion authority;
- unknown license is reference-only;
- non-commercial licensing is reference-only for Sazan commercial work;
- private repository metadata is not persisted in the public repository;
- executable integrations require reproducible lab evidence;
- rollback is mandatory;
- observed reverse-engineering claims require evidence;
- inferred claims require evidence plus rationale.

## C002 starting point

Move from individually verified layers to an end-to-end production pipeline.

Priority work:

5. process/execution-flow synthesis;
6. normalized diff-to-impact reports;
7. token-budgeted graph/context responses;
8. provider health, timeout, retry, and fallback policy;
9. cache/incremental-index strategy;
10. end-to-end integration lab using a realistic multi-repository fixture.
