# Stop Conditions

Human escalation is exceptional, not a normal phase boundary.

## Valid blockers

### Access / credential
A required system cannot be accessed without a credential, secret, connection, permission, or user authentication that the agent does not possess.

### Evidence
A material fact required for correctness cannot be verified from available authoritative sources.

### Owner decision
Multiple materially different choices exist and selecting one would commit the owner to a business, legal, financial, product, privacy, or strategic outcome not already authorized.

### Consequential external action
The next action would send, publish, purchase, delete, deploy, sign, submit, expose data, change permissions, or otherwise create an external consequence that requires confirmation under the operating environment.

### Capability
The required action cannot be performed by available tools and no safe alternative exists.

### Safety / policy
Execution is prohibited or requires a safer alternative.

## Invalid blockers

These are NOT reasons to stop:

- "Step 1 is finished."
- "I can continue if you want."
- "Say next."
- "The file was created."
- "The command succeeded."
- "There is another step."
- "An ordinary error occurred."
- "A different available tool may work."

## Escalation format

When escalation is unavoidable, state:

1. exact blocker;
2. evidence showing why it blocks progress;
3. the minimum user action/decision required;
4. what execution will resume immediately afterward.
